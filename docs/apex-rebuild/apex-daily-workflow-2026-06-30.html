_job_prospect — Auto-Prospecting

12:00 UTC daily · agents/prospector.py
Trigger
12:00 UTC daily
Config
5 Supabase settings keys
Dedupe key
Google Maps place_id
Heartbeat
agent_health.prospect_cron
  • Reads cron_prospect_types (e.g. "dentist,salon"), cron_prospect_cities, cron_prospect_max (default 10), and a JSON cursor from Supabase settings
  • Advances one (type, city) pair per run — rotates through all pairs day by day
  • Runs 4 synonym passes per vertical (e.g. "dentist" → dental clinic, dental practice, dentistry, dental surgery) to maximise coverage without duplicate Detail API calls
  • Each new lead immediately passed through enrichment.py — 8 signals scored: poor hours, low reviews, missing website, job ad detected, no booking widget, Google rating <4.0, solo operator, recent opening
  • pain_score (0–100), pain_signal, pain_finding written to lead record
  • Skips any place_id already in the leads table
  • Alert fired if any exception — watchdog also catches extended silence

Section 07

Watchdog — Health Monitoring

Fires every hour at :45, 7 days a week. Reads the agent_health Supabase table where every cron job writes a heartbeat at the end of its run (upsert_heartbeat()). Compares last heartbeat to expected cadence. De-duped to avoid alert spam.

Alert Severity Tiers
Warning
Job slightly overdue. Logged. No immediate alert unless it persists to the next check.
Critical
Job significantly overdue or dependency probe failed. WA + email alert to founder.
Emergency
Multiple jobs down or core dependency (Supabase, Anthropic) unreachable. Immediate dual-channel alert.
Dependency probes (raw HTTP — no SDK)
  • Anthropic API — requests.get() to health endpoint
  • Supabase — REST ping
  • Meta WhatsApp API — token validation
  • Vapi — account check
  • SDK methods forbidden in probes — version pinning caused false Anthropic alerts previously
Founder alert channels
  • WhatsApp via Meta UTILITY templates: apex_system_alert (critical) and apex_daily_brief
  • Email via Resend — always-on failsafe, fires even if WA fails
