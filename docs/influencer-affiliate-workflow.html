End-to-End Workflow
📋
STEP 1 You paste Instagram URLs
Paste one or more Instagram profile URLs into the Apex dashboard Influencers tab. These are advocates you've found manually via hashtag search or referrals.
Example input:
https://www.instagram.com/advocate.delhi/
https://www.instagram.com/rahul_lawyer_mumbai/
https://www.instagram.com/highcourtadvocate/
🔍
STEP 2 Apify scrapes profile data
The influencer_discovery.py agent calls the Apify instagram-profile-scraper actor with the URL list. Returns structured data for each profile.
Data returned per profile: follower count · following count · post count · bio text · is_verified · recent post captions · external URL
🧮
STEP 3 Agent scores and filters
Python scoring logic qualifies each profile automatically before it reaches your review queue.
Strong — 1,000–50,000 followers · bio contains advocate/LLB/court/law · posts ≥ 10

Moderate — follower range OK but bio unclear, or low post frequency

Skip — under 500 followers · no legal keywords · private account
📞
STEP 4 Bio parser extracts contact info
Most Indian advocates include their WhatsApp number in their bio. A regex parser extracts Indian mobile numbers (+91 or 10-digit) and emails from the bio text.
Patterns detected: +91XXXXXXXXXX  ·  9XXXXXXXXXX  ·  name@domain.com

Phone found → flagged WA Ready
No phone → flagged DM Only
✍️
STEP 5 Claude drafts personalised outreach message
Claude Haiku generates a personalised message per candidate using their name, follower count, and bio content. Tone is peer-to-peer, not corporate.
Message references their specific content theme (e.g. consumer law, criminal practice, family court) and leads with a pain-point question before introducing the affiliate offer.
Delivery Branch — Based on Contact Info Found

📱 WA Ready — Phone number found in bio

Message goes through the existing Apex WhatsApp outreach pipeline (outreach.py). You review the drafted message in the dashboard, edit if needed, and click Send. Delivered via the outreach number +1 385-363-3720.

Fully automated after your approval

💬 DM Only — No phone number in bio

Claude drafts an Instagram DM message. The dashboard shows a copy button so you can paste it into Instagram manually. No automation possible here without violating Instagram ToS on sending.

Message drafted, manual send
