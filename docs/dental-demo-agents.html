Technical Notes
Phone routing (inbound): For the demo, +1 208-441-4485 is the SignalWire number. To make it ring Henry, configure an inbound SIP rule in SignalWire to forward calls to Dograh's SIP endpoint for Henry's workflow via Cloudonix. Henry and Emma both use telephony config 598.

Canadian area code: +1 208 is Idaho, USA — but NANP means it calls Canada perfectly fine. A true Toronto 416 number can be acquired from VoIP.ms later if needed for a more polished demo.
Before showing the demo: Call +1 208-441-4485 yourself and verify Henry answers. Then trigger Emma to call your personal number with call_type=appointment_reminder and verify the script sounds right. Check Dograh dashboard for call recordings of both tests.
