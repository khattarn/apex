Voice Agent Migration — Dograh → Vapi

PracticeDesk Dev Team Handover  ·  Completed: 2026-06-27  ·  Prepared by: Neeraj Khattar  ·  Railway deploy: 5e64ed7

1 What Changed and Why

All US/Canada voice agents have been migrated from Dograh + Cloudonix/Twilio to Vapi.ai. Indian operations (Priya) remain on Dograh + Vobiz and are not affected by this change.

Why Dograh was retired for US/CA: Dograh's inbound webhook (config 598 / Cloudonix) was silently broken — all inbound calls returned an immediate hangup because the webhook requires a live Cloudonix SIP session. HTTP-only invocations always returned <Response><Hangup/>. The Twilio outbound number (+13187706725) was also blocked with error 21216 (compliance hold). Both issues had no near-term fix.
Result: All four US/CA agents (Henry, Sophie, Claire, Emma) are now live on Vapi with confirmed inbound and outbound calls tested end-to-end.

2 Two-Tier Agent Architecture

This is a critical distinction — the two tiers use different LLM prompts, different phone numbers, and must never be mixed.

Tier 1 — PracticeDesk Platform Agents

Generic prompts. Serve the PracticeDesk SaaS product itself — for prospects and leads, not for any individual client's patients. Context (practice name, type, city) is injected per call via variableValues.

Agents: Henry (inbound) · Sophie (outbound sales)
Tier 2 — Individual Pro-Client Agents (Bright Smile Dental demo)

Fully hardcoded for one specific practice. Contains clinic name, doctor name, hours, fees, recall scripts etc. For Bright Smile Dental's existing patients — not for sales.

Agents: Claire (inbound receptionist) · Emma (outbound patient care)
