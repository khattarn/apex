Dograh Agent Setup Guide

How to configure inbound and outbound voice agents in the Dograh workflow builder — with exact node content, toggle settings, and a reusable Knowledge Base template.

How Dograh Works
Dograh uses a node-based workflow canvas. Each workflow has 4 nodes: Global, Start, Main Agenda, and End Call. The Agent Builder auto-generates this structure — you then customise each node. The public API only supports triggering calls, not creating or reading workflows. All setup is done through the dashboard at app.dograh.com.
Global Node
Persona · Practice details · Guardrails · Runs in all nodes when Add Global Prompt is ON
Start Node
Greeting Text (spoken) · Call flow logic · Earn the right to continue
Main Agenda
The actual conversation · Scripts · Booking flow · Objection handling
End Call Node
Brief farewell only · End immediately · No new topics

Recommended Approach — Knowledge Base + Thin Prompt
For production use: separate the agent persona from the client knowledge. The Global Node holds the agent's persona and rules (reusable across clients). A Knowledge Base document holds all the practice-specific details (services, fees, hours, FAQ). Attach the KB to the Main Agenda node. To onboard a new client: duplicate the workflow, swap the KB document. Done.
WITHOUT Knowledge Base
  • All practice details embedded in prompts
  • Must rewrite prompts for each new client
  • Easy to make mistakes updating node content
  • Fine for a single demo practice
WITH Knowledge Base ✓
  • Practice details in a separate document
  • Duplicate workflow + upload new KB = new client
  • Prompts stay clean and version-controlled
  • Scale to 10, 50, 100 practices without prompt surgery

Setup Guide — Inbound Agent
📞
Inbound Receptionist
Answers calls · Books appointments · FAQ · Emergency handling · Example: Claire at Bright Smile Dental
1
Create the Workflow in Dograh
app.dograh.com → Voice Agents → New
  • Click Agent Builder (not Blank Canvas)
  • Use Case: Customer Service
  • Activity description: Answer inbound calls for a [vertical] practice. Book appointments, answer questions about hours, services, and fees, handle emergencies, and collect patient details for confirmation.
  • Dograh generates the 4-node workflow automatically
  • Rename the workflow: "[Agent Name] — [Practice Name]" (e.g. Claire — Bright Smile Dental)
  • Set voice via the ⚙️ gear icon on the canvas — choose a voice that matches the agent's persona
  • Set telephony configuration to 598 (international/Canada) or 477 (India)

Setup Guide — Outbound Agent
💛
Outbound Patient Care
Reminders · Recall · Check-in · No-show follow-up · Example: Emma at Bright Smile Dental
Outbound agents read a call_type variable passed via initial_context at trigger time to decide which script to run. Variables are accessed in prompts as {{call_type}}, {{patient_name}}, {{appointment_time}}.

Variables reference

VariableValuesRequired
{{call_type}}appointment_reminder · six_month_recall · post_treatment_checkin · no_show_followupAlways
{{patient_name}}Patient's first nameAlways
{{appointment_time}}e.g. "10:00am Thursday"appointment_reminder only
1
Create the Workflow in Dograh
app.dograh.com → Voice Agents → New
  • Click Agent Builder
  • Use Case: Outbound Call
  • Activity description: Call existing patients for appointment reminders, 6-month recall check-ups, post-treatment check-ins, and no-show follow-up. Warm, brief calls under 90 seconds.
  • Rename the workflow: "[Agent Name] — [Practice Name]"
  • Set voice via gear icon — warm female voice recommended
  • Set telephony to 598 (international/Canada) or 477 (India)
2
Global Node
Yellow node · Replace OVERALL GOAL only
